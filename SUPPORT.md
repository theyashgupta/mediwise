# Support

One person maintains MediWise in their spare time. These steps get you an answer fastest.

## Setup questions

Start with the [README](README.md). The [Quick start](README.md#quick-start) covers the tools, the env files and the first run. [docs/DEPLOY.md](docs/DEPLOY.md) covers production.

Still stuck? [Open an issue](https://github.com/theyashgupta/mediwise/issues/new/choose) with the command you ran and the full output. Remove every key and every value from your `.env` files before you paste output.

## Something is broken

[Open a bug report](https://github.com/theyashgupta/mediwise/issues/new/choose). A reliable way to reproduce the bug helps most. Reproduce it with the sample reports in `apps/api/fixtures/golden`, not with a real report.

## A marker looks wrong

Open a bug report with the marker name, the value, the unit and the range the lab printed. Do not attach the report.

## Security problems

Do not post them in public. [SECURITY.md](SECURITY.md) explains how to report them in private.

## Medical questions

MediWise cannot answer them. Ask your doctor.

## Response times

Best effort. Security reports and bugs come first.
