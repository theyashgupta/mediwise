# Copy audit (MEDI-20)

This file lists every user-facing string that MEDI-20 changed to follow `.claude/rules/copy.md` and the `asd-ste100` skill. Each row gives the before text, the mode, and the after text.

- Strict mode: errors, instructions, follow-ups, buttons, toasts and anything the user acts on.
- STE-flavored mode: explanations, catalog prose and body copy.
- A string that already complied stays as it was. Each section names the files we checked and did not change.

## Names

The app uses one name for each thing.

| Thing | Name | Do not use |
|---|---|---|
| The uploaded lab file and its result page | report | document, lab report (as a name), results |
| A measured analyte, for example HbA1c or LDL | marker | biomarker, test (as a noun for the analyte), parameter |
| The number or text the lab printed for a marker | value | reading, result |
| The lab procedure | test, retest | repeat test, draw |
| The record for one person | profile | person, member |
| A profile that is not the account owner | family member | relative, dependant |
| The medical professional | doctor | clinician, physician |
| What MediWise does with an upload | read | process, analyse, scan |
| The range for age, sex and ancestry | calibrated range | your range, personal range |
| The range the lab printed | lab range | reference range |
| Status bands | optimal, watch, risk | normal, borderline, abnormal |

## Checks

- `packages/engine/src/catalog/index.test.ts` fails when a catalog copy field has a semicolon or a sentence over 20 words.
- A script compared the catalog before and after the rewrite. Every number in every changed field is the same. Hedge words keep the same strength. For example, "points toward" became "suggests" and "goes with" became "is linked with".
- `packages/engine/fixtures/*.expected.json` changed only in text fields (follow-up `why` and `next`, and the verdict).

## Extraction prompts

No change. The two prompts in `apps/api/src/modules/extraction/extraction.service.ts` make Claude call a tool that records values or catalog keys. Neither prompt produces prose that a user reads. The copy rules go into the system prompt of the first prompt that writes user prose (MEDI-17 narrative).

## Kept on purpose

- The API problem titles `Not Found` and `Internal Server Error` stay. RFC 9457 says that a problem with type `about:blank` uses the HTTP status phrase as its title.
- `packages/engine/src/rank.ts` keeps "your optimal range". The engine falls back to the lab range when no calibrated range applies, so "calibrated range" would be wrong there.
- `apps/api/src/modules/trends/trends.schemas.ts` keeps "Give b or profileId". It names the query parameters of the compare endpoint, and the web always sends one of them.
